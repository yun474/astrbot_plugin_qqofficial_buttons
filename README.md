## ✨ 功能亮点

| 功能 | 可以做什么 |
| --- | --- |
| 🎛️ 可视化工作台 | 创建、复制和管理多个菜单，拖动按钮，导入导出配置 |
| 📝 图文菜单 | 支持几乎所有 QQ 官方原生 Markdown 正文格式，图片可放在正文任意位置 |
| 👋 艾特发起者 | 插入 `{{at}}`，自动艾特点开菜单的人 |
| 🔵 蓝字快捷指令 | 在正文插入可点击指令，表单生成，无需手写标签 |
| 🧩 自定义按钮 | 发送指令、填入输入框、打开链接、回复文字、跳转菜单 |
| ⚡ 原生回调 | 点击后回复文字、打开菜单、执行带参数的已注册指令，或唤醒 AstrBot 按提示词回复 |
| 🗝️ 使用权限 | 设置所有人、QQ 群管理员、AstrBot 管理员、仅触发者本人、指定用户或频道身份组可点击 |
| 🖼️ 素材库 | 图片上传到 QQ 官方图床或使用本机图片，无需公网地址 |
| 🤖 LLM 调用 | 让模型发送你配置好的菜单，可选允许临时生成普通按钮 |
| ／ 指令面板 | 配置用户输入 `/` 时弹出的指令列表，可按场景分开配，也可以只给指定的群或用户 |

支持 `qq_official` 和 `qq_official_webhook`。QQ 标签和按钮的实际效果取决于会话场景及机器人权限；工作台提供近似预览。

<a id="usage"></a>

## 🚀 创建第一个菜单

使用 **AstrBot 4.26.0 或更高版本**，连接 QQ 官方机器人，并开通所需的 Markdown／消息按钮权限。在插件管理中通过[本仓库](https://github.com/yun474/astrbot_plugin_qqofficial_buttons)安装。

```text
AstrBot WebUI → 插件管理 → QQ官bot自定义菜单 → 按钮工作台
```

1. 选择示例菜单，或点击“新建按钮组”。
2. 填写正文，点“自定义指令”旁的“修改”，添加 `/菜单`；可以添加多个。
3. 点击“＋ 添加一行”，再点行内“＋ 按钮”；选中按钮设置文字和点击动作。
4. 保存并启用菜单，在 QQ 中发送菜单指令。

**唤醒词跟随 AstrBot。** 配置框统一填写 `/菜单`，如果 AstrBot 的唤醒词是 `!`，实际发送 `!菜单`。避免与其他插件的指令重名。

<a id="markdown"></a>

## 📝 编辑图文正文

### 艾特用户与基本排版

```markdown
# 功能菜单
{{at}}，欢迎使用！

**常用功能**
- 查看帮助
- 打开其他菜单
```

`{{at}}` 仅用于菜单正文，无需填写用户 ID。回调打开其他菜单时，艾特的是本次点击者；私聊不保证显示可点击的艾特。<br>
> 注意QQ在实际渲染时@消息可能被放在md的最上方。

### 插入图片

先在正文里点一下要放图片的位置，再展开“插入图片”：选图片来源（公网链接、素材库、本机图片，见下方[图片来源](#图片来源)），填好宽高，点击“插入图片到正文光标处”。可重复插入多张图片，只有点了插入的图片才会发出去。

也可以直接写：

```markdown
图片上方的文字

![菜单图 #208px #320px](https://example.com/menu.png)

图片下方的文字
```

替换为真实图片地址。旧版本单独填写的菜单图片，在工作台打开时会自动转成正文末尾的一行图片，发送效果不变，之后可以挪到想要的位置。

### 图片来源

| 写法 | 例子 | 说明 |
| --- | --- | --- |
| 公网 HTTPS | `https://example.com/menu.png` | 图片需能从公网访问 |
| 素材库链接 | `qqbot-media://image/v1/…` | 点“从素材库选择”挑图（带缩略图，已过期的不可选），或粘贴在素材库中复制的链接；90 天内被使用过就一直有效 |
| 本机图片 | `local://banner.png` | 从固定目录的下拉列表中选择，前缀自动加上；每次发送时临时上传、发完即删，不长期占用额度 |

**素材库**：点工作台最左侧的“素材库”切换过去，可以上传、查看和删除 QQ 官方图床里的图片，再点“工作台”切回来，没保存的修改不会丢。上传按钮按存放位置分开：“QQ 素材库”区域的“上传到 QQ 素材库”传到 QQ 云端，“本机图片”区域的“上传到本机目录”存进 AstrBot 所在机器。每个机器人最多 100 张，单张 10MB 以内，支持 png、jpg、gif、webp。素材链接只对上传它的机器人有效；90 天内没有被消息使用会自动过期，每次使用重新计时。删除后链接立即失效，已发出的消息不受影响。

**本机图片**：只能使用插件数据目录下 `images` 文件夹里的图片，这个目录是固定的，不能更改（素材库里会显示完整路径）。可以在素材库点“上传到本机目录”，也可以直接把图片放进文件夹，然后在工作台选“本机图片”，从下拉列表中选文件即可，不支持子文件夹。上传时会检查文件确实是图片，文件名里的空格、括号等字符会换成下划线，重名时自动加序号，不会覆盖已有图片。直接放进文件夹的图片，文件名不能含空格、括号和 `\ / : * ? " < > |`，最长 100 个字符，否则不会出现在列表里，素材库会列出这些文件提醒改名；菜单引用的图片被移走时，列表会标出“目录里找不到”。保存菜单时也会检查图片是否存在。每次发送需要素材库至少空出 1 张额度，发送会多花一两秒。

素材链接和本机图片只能在 Markdown 消息中显示；QQ 不允许 Markdown、退回纯文字发送时，正文里的公网图片会改写为“图片：链接”，素材链接和本机图片不显示。

### 插入蓝字指令

展开“插入蓝字快捷指令”，填写指令、显示文字和引用选项，再点击插入。比如指令填 `/插件菜单`，显示文字填“查看更多功能”。

标签的可读形式如下，日常使用表单即可自动处理编码：

```html
<qqbot-cmd-input text="/插件菜单" show="查看更多功能" reference="false" />
```

“填入输入框”需要用户确认发送；蓝字标签的“直接发送”不支持群聊和文字子频道。需要点击即执行时，可使用下方的**原生回调：执行指令**按钮。

预览支持图文、蓝字、艾特和子频道标签；系统表情显示 ID 占位。

## 🧩 设置按钮动作

选中按钮，在右侧“点击动作”选择：

| 动作 | 填写内容 | 点击效果 |
| --- | --- | --- |
| 发送指令 | 如 `/help` | 发送配置的指令或文字 |
| 填入输入框 | 指令或文字 | 填入后由用户确认发送 |
| 打开链接 | HTTPS 网页地址 | 打开网页 |
| 回复固定文字 | 回复内容 | 插件回复这段文字 |
| 打开另一按钮组 | 目标菜单 ID | 发送目标菜单 |
| 原生回调：回复文字 | 回复内容 | 点击直接回复，不产生用户指令消息 |
| 原生回调：打开菜单 | 目标菜单 ID | 点击直接发送目标菜单 |
| 原生回调：执行指令 | 如 `/天气 北京 3` | 以点击者身份执行指令并回复结果 |
| 原生回调：直接调用 | 提示词，如 `来一句每日一言` | 由插件唤醒 AstrBot，按提示词在当前对话中回复 |

固定回复、菜单跳转和回调动作需要开启“启用插件功能按钮”。目标菜单 ID 可在对应菜单的编辑页面查看。

### 谁可以点击

| 权限 | 效果 |
| --- | --- |
| 所有人 | 任何人都能点击 |
| 仅 QQ 群管理员 | 由 QQ 客户端校验，只有群主、群管理员或频道管理员能点击 |
| 仅 AstrBot 管理员 | 只有 AstrBot 后台“管理员 ID”中的用户能使用，其他人点击会被插件拒绝；只能用于插件功能按钮和原生回调 |
| 仅触发者本人 | 只有发出这次菜单指令（或点开这个菜单）的人能点击，适合欢迎菜单、个人设置等按钮 |
| 指定用户 OpenID | 只有填写的用户能点击，可点“选择用户”搜索添加 |
| 指定频道身份组 | 只有填写的频道身份组成员能点击 |

> 管理员专用的功能按钮推荐使用原生回调动作。“回复固定文字／打开另一按钮组”会在会话中发出一条内部指令，这条指令可以被复制重发。

“仅触发者本人”需要知道是谁触发了菜单，定时任务等没有触发者的场景无法发送这类按钮。

**由插件拦截并回复拒绝语**：默认由 QQ 客户端拦截，没权限的人点不了，只能看到 QQ 自带的提示。“仅触发者本人”和“指定用户 OpenID”用在插件功能按钮或原生回调上时，可以勾选“由插件拦截”：QQ 里所有人都能点，没权限的人会收到一条拒绝语。“仅 AstrBot 管理员”本来就由插件拦截，直接显示拒绝语。

- 点拒绝语旁的“修改”逐条添加，每次随机发一条；写 `{{at}}` 会艾特点击者。
- 默认是“这个按钮没给你操作权限，别乱戳啦。”，与旧版一致；全部清空则静默拒绝，不发任何消息。
- 同一个人在同一会话里被拒后，冷却期内（默认 10 秒）再点不再回复，可在配置“拒绝语冷却秒数”中修改，填 0 关闭。
- 拦截方式和拒绝语可以随时修改，已发出的菜单不会失效；但切换拦截方式后，需要重新发送菜单，QQ 那边能不能点才会跟着变。

**选择用户**：设置“指定用户 OpenID”时，点“选择用户”可以按 OpenID 或来源群名搜索在 QQ 里和机器人说过话的用户，勾选后确定即可；搜不到时可以把输入的 OpenID 直接添加，也可以点“修改”逐条手动添加。QQ 官方机器人拿不到群成员昵称，列表主要显示 OpenID 和来源群名。搜索已记录用户需要 AstrBot v4.29.4 及以上，旧版本只能手动添加。

### 直接调用：点一下就说话

选“原生回调：直接调用”，在动作内容里写清楚要 bot 说什么，比如：

- `来一句每日一言，短一点，别说教`
- `夸一下刚刚按按钮的人，一句话就够`

点击后由插件唤醒 AstrBot，在当前会话的对话里发起一次模型请求，和平时聊天走同一套流程：人格、对话记忆、其他插件的 LLM 钩子（如记忆类插件）、工具调用，以及分段回复、文字转图片等回复设置都照常生效，插件不另加回复限制。提示词作为系统要求传给模型，对话记录里只留下一句“（点击了按钮「按钮文字」）”和模型的回复，不会记成点击者说的话，也不会被当成指令执行；设置了 LLM 唤醒前缀也能正常回复。模型出错时的提示由 AstrBot 决定。

几个按需使用的小功能：

- **`{user}` 占位符**：写在提示词里，会替换成点击者的 OpenID，例如 `夸夸 {user}`。
- **回复时艾特点击者**：选择直接调用后，动作内容下方会出现这个勾选框，默认关闭。勾选后在 AstrBot 发出回复前于开头艾特点击者，艾特本身不发给模型；开启分段回复时艾特和第一段文字一起发出，开启流式输出时这类按钮的回复会整段发送，保证带上艾特。回复默认按 Markdown 发送，艾特才能正常显示；没有 Markdown 权限时自动改发纯文字。如果已在 AstrBot 中开启“回复时@发送者”，就不用再勾选，否则会艾特两次；回复较长被转成图片时艾特无法显示。

为避免同一个人连续点击刷屏，冷却期内（默认 10 秒）重复点击不会再回复，QQ 会提示操作频繁；可在配置中修改，填 0 关闭。

### 回调执行带参数指令

> **兼容性提示：此功能不能保证兼容所有插件。** 使用 AstrBot 标准消息发送方式的插件可尝试使用；自行发送 HTTP 请求或依赖真实用户消息 ID 的插件可能被 QQ 拒绝，出现 `40034024` 等错误。已发现“小猪收集册”的独立发送方式存在此问题。遇到这种情况，请将按钮改为“发送指令”或“填入输入框”，让用户通过 QQ 发送真实指令消息。

1. 选择“原生回调：执行指令”。
2. 填写 `/指令 参数1 参数2`，例如 `/天气 北京 3`，指令需已由其他插件注册。
3. 保存后点击测试。支持指令别名和子指令，管理员指令仍需点击者有权限。

**回调指令自动适配当前会话的唤醒词**。可填 `天气 北京`，也兼容 `/天气 北京`；唤醒词为 `!` 时还可填 `!天气 北京`。普通“发送指令”、输入框按钮和蓝字标签按填写内容原样使用，需要自己填正确前缀。普通“回复固定文字／打开另一按钮组”目前依赖 `/` 前缀；使用自定义唤醒词时，请选择对应的原生回调动作。

首次使用回调：

- **WebSocket**：安装或热重载插件后，重载 QQ 平台连接。
- **Webhook**：在 QQ 开放平台订阅 `INTERACTION_CREATE` 事件。

## 🤖 让 LLM 发菜单

在菜单中开启“允许 LLM 调用”，模型即可通过 `send_qq_official_buttons` 工具发送该菜单。菜单按工作台里设计的正文原样发送，模型不能改写，图片、艾特和蓝字指令都会保留。
> 应用场景：
> > 在提示词中完善：当用户询问“你有什么功能”时，使用`send_qq_official_buttons`工具发送`主菜单`。

如需模型临时生成按钮，再开启“允许 LLM 临时生成按钮”。临时按钮支持指令、填入输入框和链接，正文由模型自己填写。

## ／ 指令面板

用户在 QQ 里输入 `/` 或 @机器人 时，会弹出机器人的指令面板。点工作台最左侧的“指令面板”即可管理，面板直接保存在 QQ 服务器上，插件本地不存副本。

比 QQ 开放平台管理端多出来的能力：

| 能力 | 管理端 | 插件 |
| --- | --- | --- |
| 每个面板的指令数 | 10 条 | 20 条 |
| 面板数量 | 1 个 | 每个机器人最多 20 个（所有场景合计） |
| 按场景分开配 | — | 单聊、群聊、文字子频道、频道私信各配各的 |
| 只给指定群或用户 | — | 群聊可指定群，单聊可指定用户 |
| 某条指令仅管理员可点 | — | 每条单独设置 |

1. 点左上角的“选择机器人”确认要管理哪个机器人，每个机器人的面板各自独立。没有接入这个 AstrBot 的机器人也可以手动添加，见下方“选择机器人”。
2. 点“＋ 新建面板”，选择生效场景和对谁生效。**场景和生效范围创建后不能修改**，想换需要新建；指定的群或用户可以随时增删。
3. 点“＋ 添加指令”，选择“发送指令”（点击后填入输入框）或“打开页面”（跳转 HTTPS 网页），填写指令和说明。指令最多 7 个汉字（14 个英文字符），说明最多 15 个汉字（30 个英文字符）。
4. 点“保存到 QQ”。客户端显示可能有延迟；QQ 版本较旧时可能看不到面板。

**指定群或用户**：可以直接填写 OpenID，也可以点“选择群／选择用户”，从这个机器人记录过的会话里挑（需要 AstrBot v4.29.4 及以上）。QQ 给每个机器人分配的用户 ID 不同，同一个人在私聊和群聊里的 ID 也不同，所以单聊面板只能选和这个机器人私聊过的用户。

> 指令面板与管理端“高级设置”里的配置可能互相影响，建议只在一处修改。

### 选择机器人

素材库和指令面板顶部都有“🤖 选择机器人”按钮，两个页面共用当前选中的机器人，在一个页面切换，另一个页面也会跟着换。

- **已连接**：AstrBot 里已经连上的 QQ 官方机器人，直接选即可。
- **手动添加**：在弹窗下方填写 QQ 开放平台“开发设置”里的 AppID 和 AppSecret，备注选填。添加前会先向 QQ 验证，填错会直接提示。同一个 AppID 再添加一次可以更新密钥和备注。

手动添加的机器人只用来管理素材库和指令面板，不会收发消息，所以没有会话记录，给指令面板指定群或用户时要直接填 ID；它的素材链接也只有它自己能发，所以这个 AstrBot 没连接它时，这些图片插进菜单也发不出去。密钥保存在插件数据目录的 `bots.json` 里，页面上不会再显示；删除只会删掉这里保存的 AppID 和密钥，不影响 QQ 上的数据。

## ⚙️ 常用配置

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| 按钮消息承载模式 | `auto` | 建议保持默认；`markdown` 使用图文，`content` 使用普通正文 |
| 发送前校验 Markdown 图片转存 | 开启 | 群聊和私聊发图前检查图片是否转存成功 |
| 图片转存失败时的最大发送次数 | 3 | 包含首次发送，可设置 1～10 次 |
| 启用插件功能按钮 | 开启 | 使用固定回复、菜单跳转和回调 |
| 直接调用按钮冷却秒数 | 10 | 同一个人连续点击直接调用的间隔，0 为不限制 |
| 拒绝语冷却秒数 | 10 | 同一个人被插件拒绝后再次回复拒绝语的间隔，0 为不限制 |
| 允许 LLM 临时生成按钮 | 关闭 | 按需开启 |
| 允许 HTTP 链接 | 关闭 | 默认按钮链接使用 HTTPS |
| 每个按钮组最大行数 | 5 | 可设置 1～5 行 |
| 每行最大按钮数 | 5 | 手机端建议每行 2～3 个 |

普通正文模式不渲染 Markdown。菜单正文最多 2000 字符；配置迁移可使用工作台的 JSON 导入导出。

## 🔎 常见问题

| 情况 | 怎么处理 |
| --- | --- |
| 菜单指令没反应 | 检查是否保存启用、唤醒词是否正确、是否与其他插件指令重名 |
| 有正文但没有按钮 | 检查 QQ 消息按钮权限，尝试更新 QQ 客户端 |
| 无法新增行或按钮 | 检查是否达到配置中的行数或按钮数上限 |
| 图片发不出来 | 确认图片直链可从公网访问且未过期 |
| 素材图片显示不出来 | 素材可能已过期或被删除，或是由其他机器人上传的，到素材库重新上传后更新链接 |
| 本机图片发送失败 | 确认图片在 images 文件夹里，素材库没有满 100 张 |
| 放进文件夹的图片不在列表里 | 文件名含空格、括号等字符或过长，按素材库提示改名后点“刷新”，或用“上传到本机目录”重新上传 |
| 回调没反应 | 开启功能按钮；WebSocket 重连平台，Webhook 检查事件订阅 |
| 回调指令执行失败 | 确认目标指令已启用、参数正确、点击者有使用权限 |
| 更新后旧功能按钮失效 | 重新发送菜单即可；修改按钮动作或权限后也需要重新发送 |
| 直接调用没反应或报错 | 先在群里 @bot 聊一句确认模型能正常回复；确认会话未停用、未关闭 AI 对话、插件已启用，按钮权限与“启用插件功能按钮”都要满足 |
| 直接调用提示操作频繁 | 处于冷却时间内，稍后再点或调整“直接调用按钮冷却秒数” |
| 仅触发者按钮发不出去 | 当前发送场景读不到触发者，改用其他权限或通过指令触发菜单 |
| 管理员点不了“仅管理员”按钮 | 2.1.0 起拆分为“仅 QQ 群管理员”和“仅 AstrBot 管理员”，按需重新选择后重发菜单 |
| 蓝字显示为源码 | 使用表单重新插入；确认使用 Markdown 模式及受支持的会话场景 |
| 指令面板保存成功但 QQ 里看不到 | 稍等一会儿或重新打开会话；更新 QQ 客户端；确认面板场景、生效对象和当前会话一致 |
| 某个场景显示读取失败 | 机器人可能没开通该场景（如频道），不影响其他场景的面板 |
| 手动添加的机器人提示获取凭证失败 | 密钥可能在 QQ 开放平台重置过，用新的 AppSecret 再添加一次同一个 AppID 即可 |

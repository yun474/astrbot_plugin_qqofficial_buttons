<a id="features"></a>

## ✨ 功能亮点

| 功能 | 可以做什么 |
| --- | --- |
| 🎛️ 可视化工作台 | 创建、复制和管理多个菜单，拖动按钮，导入导出配置 |
| 📝 图文菜单 | 支持几乎所有 QQ 官方原生 Markdown 正文格式，图片可放在正文任意位置 |
| 👋 艾特发起者 | 插入 `{{at}}`，自动艾特点开菜单的人 |
| 🔵 蓝字快捷指令 | 在正文插入可点击指令，表单生成，无需手写标签 |
| 🧩 自定义按钮 | 发送指令、填入输入框、打开链接、回复文字、跳转菜单 |
| ⚡ 原生回调 | 点击后回复文字、打开菜单，或执行带参数的已注册指令 |
| 🗝️ 使用权限 | 设置所有人、管理员、指定用户或频道身份组可点击 |
| 🤖 LLM 调用 | 让模型发送你配置好的菜单，可选允许临时生成普通按钮 |

支持 `qq_official` 和 `qq_official_webhook`。QQ 标签和按钮的实际效果取决于会话场景及机器人权限；工作台提供近似预览。

<a id="usage"></a>

## 🚀 创建第一个菜单

使用 **AstrBot 4.24.2 或更高版本**，连接 QQ 官方机器人，并开通所需的 Markdown／消息按钮权限。在插件管理中通过[本仓库](https://github.com/yun474/astrbot_plugin_qqofficial_buttons)安装。

```text
AstrBot WebUI → 插件管理 → qq官bot自定义菜单 → 按钮工作台
```

1. 选择示例菜单，或点击“新建按钮组”。
2. 填写正文，在“自定义指令”中填写 `/菜单`；多个指令一行一个。
3. 点击“＋ 添加一行”，再点行内“＋ 按钮”；选中按钮设置文字和点击动作。
4. 保存并启用菜单，在 QQ 中发送菜单指令。

**唤醒词跟随 AstrBot。** 配置框统一填写 `/菜单`，如果 AstrBot 的唤醒词是 `!`，实际发送 `!菜单`。避免与其他插件的指令重名。

<a id="markdown"></a>

## 📝 编辑图文正文

### 艾特用户与基本排版

```markdown
# 功能菜单
{{at}}，欢迎使用！

**常用功能**
- 查看帮助
- 打开其他菜单
```

`{{at}}` 仅用于菜单正文，无需填写用户 ID。回调打开其他菜单时，艾特的是本次点击者；私聊不保证显示可点击的艾特。<br>
> 注意QQ在实际渲染时@消息可能被放在md的最上方。

### 插入图片

把光标放在正文目标位置，填写**公网 HTTPS 图片 URL**和宽高，点击“插入图片到正文光标处”。可重复插入多张图片。

也可以直接写：

```markdown
图片上方的文字

![菜单图 #208px #320px](https://example.com/menu.png)

图片下方的文字
```

替换为真实图片地址。只填写独立图片字段、不点插入时，图片会放在正文末尾。

### 插入蓝字指令

展开“插入蓝字快捷指令”，填写指令、显示文字和引用选项，再点击插入。比如指令填 `/插件菜单`，显示文字填“查看更多功能”。

标签的可读形式如下，日常使用表单即可自动处理编码：

```html
<qqbot-cmd-input text="/插件菜单" show="查看更多功能" reference="false" />
```

“填入输入框”需要用户确认发送；蓝字标签的“直接发送”不支持群聊和文字子频道。需要点击即执行时，可使用下方的**原生回调：执行指令**按钮。

预览支持图文、蓝字、艾特和子频道标签；系统表情显示 ID 占位。

<a id="callbacks"></a>

## 🧩 设置按钮动作

选中按钮，在右侧“点击动作”选择：

| 动作 | 填写内容 | 点击效果 |
| --- | --- | --- |
| 发送指令 | 如 `/help` | 发送配置的指令或文字 |
| 填入输入框 | 指令或文字 | 填入后由用户确认发送 |
| 打开链接 | HTTPS 网页地址 | 打开网页 |
| 回复固定文字 | 回复内容 | 插件回复这段文字 |
| 打开另一按钮组 | 目标菜单 ID | 发送目标菜单 |
| 原生回调：回复文字 | 回复内容 | 点击直接回复，不产生用户指令消息 |
| 原生回调：打开菜单 | 目标菜单 ID | 点击直接发送目标菜单 |
| 原生回调：执行指令 | 如 `/天气 北京 3` | 以点击者身份执行指令并回复结果 |

固定回复、菜单跳转和回调动作需要开启“启用插件功能按钮”。目标菜单 ID 可在对应菜单的编辑页面查看。

### 回调执行带参数指令

> **兼容性提示：此功能不能保证兼容所有插件。** 使用 AstrBot 标准消息发送方式的插件可尝试使用；自行发送 HTTP 请求或依赖真实用户消息 ID 的插件可能被 QQ 拒绝，出现 `40034024` 等错误。已发现“小猪收集册”的独立发送方式存在此问题。遇到这种情况，请将按钮改为“发送指令”或“填入输入框”，让用户通过 QQ 发送真实指令消息。

1. 选择“原生回调：执行指令”。
2. 填写 `/指令 参数1 参数2`，例如 `/天气 北京 3`，指令需已由其他插件注册。
3. 保存后点击测试。支持指令别名和子指令，管理员指令仍需点击者有权限。

**回调指令自动适配当前会话的唤醒词**。可填 `天气 北京`，也兼容 `/天气 北京`；唤醒词为 `!` 时还可填 `!天气 北京`。普通“发送指令”、输入框按钮和蓝字标签按填写内容原样使用，需要自己填正确前缀。普通“回复固定文字／打开另一按钮组”目前依赖 `/` 前缀；使用自定义唤醒词时，请选择对应的原生回调动作。

首次使用回调：

- **WebSocket**：安装或热重载插件后，重载 QQ 平台连接。
- **Webhook**：在 QQ 开放平台订阅 `INTERACTION_CREATE` 事件。

## 🤖 让 LLM 发菜单

在菜单中开启“允许 LLM 调用”，模型即可通过 `send_qq_official_buttons` 工具发送该菜单。
> 应用场景：
> > 在提示词中完善：当用户询问“你有什么功能”时，使用`send_qq_official_buttons`工具发送`主菜单`。

如需模型临时生成按钮，再开启“允许 LLM 临时生成按钮”。临时按钮支持指令、填入输入框和链接。

<a id="settings"></a>

## ⚙️ 常用配置

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| 按钮消息承载模式 | `auto` | 建议保持默认；`markdown` 使用图文，`content` 使用普通正文 |
| 发送前校验 Markdown 图片转存 | 开启 | 群聊和私聊发图前检查图片是否转存成功 |
| 图片转存失败时的最大发送次数 | 3 | 包含首次发送，可设置 1～10 次 |
| 启用插件功能按钮 | 开启 | 使用固定回复、菜单跳转和回调 |
| 允许 LLM 临时生成按钮 | 关闭 | 按需开启 |
| 允许 HTTP 链接 | 关闭 | 默认按钮链接使用 HTTPS |
| 每个按钮组最大行数 | 5 | 可设置 1～5 行 |
| 每行最大按钮数 | 5 | 手机端建议每行 2～3 个 |

普通正文模式不渲染 Markdown。菜单正文最多 2000 字符；配置迁移可使用工作台的 JSON 导入导出。

<a id="faq"></a>

## 🔎 常见问题

| 情况 | 怎么处理 |
| --- | --- |
| 菜单指令没反应 | 检查是否保存启用、唤醒词是否正确、是否与其他插件指令重名 |
| 有正文但没有按钮 | 检查 QQ 消息按钮权限，尝试更新 QQ 客户端 |
| 无法新增行或按钮 | 检查是否达到配置中的行数或按钮数上限 |
| 图片发不出来 | 确认图片直链可从公网访问且未过期 |
| 回调没反应 | 开启功能按钮；WebSocket 重连平台，Webhook 检查事件订阅 |
| 回调指令执行失败 | 确认目标指令已启用、参数正确、点击者有使用权限 |
| 更新后旧功能按钮失效 | 重新发送菜单即可；修改按钮动作或权限后也需要重新发送 |
| 蓝字显示为源码 | 使用表单重新插入；确认使用 Markdown 模式及受支持的会话场景 |
